The requested gain and GBW targets are met at TT. This is an initial schematic result, not a sign-off design: phase margin needs further compensation work, bias voltages are external pins, and PVT/Monte-Carlo/noise/slew/output-swing/post-layout checks have not yet been completed.

The continuous-time CMFB uses two 10 Mohm averaging resistors, a 20 fF sense-node capacitor, a transistor error amplifier, and a 200 fF compensation capacitor.

## Current-mirror bias and compensated TT result

The revised standalone deck uses an `analogLib/idc`-equivalent ideal DC reference current only to establish `IREF=20 uA`. All voltage biases are then generated by `nch_mac`/`pch_mac` mirrors or replica branches; no resistor divider establishes a bias voltage. A 1 kohm/45 fF series differential lead network provides phase compensation.

Spectre 18.1 at TT, 0.9 V, 27 C and 50 fF/output:

| Metric | Result |
|---|---:|
| Differential DC gain | 57.31 dB |
| Differential unity-gain bandwidth | 5.073 GHz |
| Differential phase margin | 63.21 deg |
| Output common mode | 0.4448 V |
| Supply current | 0.9660 mA |

The reproducible deck is `fc_fd_cmfb_mirror_bias_tt.scs`. The mirror/replica bias nodes at this point are approximately `VBNT=0.5702 V`, `VBPT=0.4198 V`, `VBPF=0.2256 V`, `VBNC=0.5904 V`, and `VCMREF=0.4472 V`. `optimize_fc.py` supplies the shared baseline deck and metric helpers used by the tuning scripts.

## PVT status

A 45-point sweep completed successfully across TT/SS/FF/SF/FS, 0.81/0.90/0.99 V, and -40/27/125 C. Five points simultaneously meet gain >=55 dB, GBW >=5 GHz, and phase margin >=60 degrees. Across all converged points:

| Metric | Range |
|---|---:|
| Gain | 32.75 to 62.08 dB |
| Unity-gain bandwidth | 0.226 to 6.381 GHz |
| Phase margin | 58.49 to 89.93 deg |

The main shortfall is GBW at hot/high-supply points and gain at low-supply slow-NMOS points. This is an honest characterization, not a PVT sign-off claim. Full point-by-point results are in `pvt_mirror_summary.csv` and `pvt_mirror_summary.json`. `run_mirror_pvt.py` regenerates the sweep; `tune_mirror_bias.py` contains the bias topology and TT tuning flow.

## Reproduction

`fc_fd_cmfb_tt_final.scs` is the original externally biased standalone deck. `final_summary.json` contains that baseline result. `create_fc_virtuoso.py` recreates the baseline library cells through virtuoso-bridge, and `setup_fc_maestro.py` recreates the TT ADE/Maestro setup. The integrated current-mirror bias has been verified in the standalone Spectre deck but has not yet been written back as a new OA/Virtuoso cell.
